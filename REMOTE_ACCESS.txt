УДАЛЕННЫЙ ДОСТУП - Claude Live Chat
====================================

БЫСТРЫЙ СТАРТ:
==============

1. Запустите сервер (если еще не запущен):

   python server.py

2. В НОВОМ окне командной строки запустите ngrok:

   ngrok http 5000

3. В окне ngrok найдите строку "Forwarding":

   Forwarding   https://xxxx-xx-xx-xx-xx.ngrok-free.app -> http://localhost:5000

4. Скопируйте URL (https://xxxx-xx-xx-xx-xx.ngrok-free.app)

5. Откройте этот URL на любом устройстве из любой точки мира!

ВАЖНО:
======

- Оба окна (server.py и ngrok) должны быть открыты
- URL меняется при каждом запуске ngrok
- Бесплатная версия ngrok работает 2 часа, потом нужно перезапустить

АЛЬТЕРНАТИВА (если ngrok не работает):
======================================

Используйте локальный доступ в той же Wi-Fi сети:
http://192.168.0.103:5000

ПРОВЕРКА:
=========

Локально работает: http://localhost:5000
Ngrok работает: откройте URL из ngrok в браузере

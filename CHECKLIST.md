## Развертывание (выполните сейчас)

### Шаг 1: Установка Fly CLI
```bash
powershell -Command "iwr https://fly.io/install.ps1 -useb | iex"
```

### Шаг 2: Запуск развертывания
```bash
cd C:\scripts\WebControl
deploy_flyio.bat
```

**ИЛИ вручную:**
```bash
fly auth login
fly launch
```

### Шаг 3: Проверка
```bash
fly status
fly open
```

## После развертывания

Ваше приложение будет доступно по адресу:
```
https://[ваше-имя-приложения].fly.dev
```

## Что дальше?

1. **Сохраните URL** - это ваш постоянный адрес
2. **Добавьте в закладки** на телефоне/планшете
3. **Протестируйте** - отправьте сообщение через веб-интерфейс
4. **Мониторинг** - `fly logs` для просмотра логов

## Важные моменты

⚠️ **Автозасыпание**: Приложение засыпает через 5 минут неактивности
⏱️ **Пробуждение**: Первый запрос после сна займет ~10-15 секунд
💾 **Данные**: chat_history.json сохраняется между перезапусками
🆓 **Бесплатно**: 160GB трафика/месяц, 3 VM

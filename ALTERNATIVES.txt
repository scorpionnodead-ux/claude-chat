АЛЬТЕРНАТИВЫ ДЛЯ УДАЛЕННОГО ДОСТУПА
====================================

Ngrok и Cloudflare заблокированы сетью. Вот рабочие альтернативы:

1. SERVEO (SSH TUNNEL) - САМЫЙ ПРОСТОЙ:
========================================

В командной строке:

ssh -R 80:localhost:5000 serveo.net

Вы получите URL вида: https://xxxxx.serveo.net
Работает сразу, без регистрации!

2. TAILSCALE VPN (РЕКОМЕНДУЕТСЯ):
==================================

- Скачайте: https://tailscale.com/download
- Установите на ПК и телефон
- Войдите в один аккаунт
- Используйте Tailscale IP вместо 192.168.0.103

Преимущества: безопасно, быстро, стабильно

3. ZEROTIER VPN:
================

- Скачайте: https://www.zerotier.com/download
- Создайте сеть на сайте
- Подключите устройства
- Используйте ZeroTier IP

4. PORT FORWARDING (если есть доступ к роутеру):
=================================================

- Откройте настройки роутера (обычно 192.168.0.1)
- Найдите Port Forwarding / Virtual Server
- Добавьте правило: External Port 5000 → Internal IP 192.168.0.103:5000
- Узнайте внешний IP: curl ifconfig.me
- Используйте: http://ВАШ_ВНЕШНИЙ_IP:5000

ТЕКУЩИЙ СТАТУС:
===============

✅ Локальная сеть: http://192.168.0.103:5000 (РАБОТАЕТ)
❌ Ngrok: заблокирован
❌ Cloudflare: заблокирован
✅ Serveo: должен работать (попробуйте!)
✅ VPN: работает всегда

Claude Live Chat - Web Interface
=================================

Простой веб-интерфейс для общения с Claude через браузер.

БЫСТРЫЙ СТАРТ:
==============

1. Запустите сервер:
   cd C:\scripts\WebControl
   python server.py

2. Откройте браузер:
   - На этом ПК: http://localhost:5000
   - На телефоне (та же Wi-Fi сеть): http://192.168.0.103:5000

3. Готово! Отправляйте сообщения Claude через веб-интерфейс.

ФУНКЦИИ:
========

- 💬 Живой чат с Claude
- 📜 История последних 20 сообщений
- 🔄 Автообновление каждые 3 секунды
- 📱 Адаптивный дизайн для мобильных устройств
- ⚡ Мгновенная отправка команд

КАК ЭТО РАБОТАЕТ:
=================

1. Вы отправляете сообщение через веб-интерфейс
2. Сообщение сохраняется в commands.txt
3. Claude читает команды и отвечает
4. Ответы появляются в чате автоматически

ДОСТУП С ТЕЛЕФОНА (локальная сеть):
====================================

1. Убедитесь что телефон и ПК в одной Wi-Fi сети
2. Откройте Safari/Chrome на телефоне
3. Введите: http://192.168.0.103:5000
4. Добавьте на главный экран для быстрого доступа

УДАЛЕННЫЙ ДОСТУП (из любой точки мира):
========================================

1. Запустите: python server.py
2. В новом окне: ngrok http 5000
3. Скопируйте URL из окна ngrok (https://xxxx.ngrok-free.app)
4. Откройте этот URL на любом устройстве

Подробнее: REMOTE_ACCESS.txt

ФАЙЛЫ:
======

- server.py - Flask сервер
- templates/chat.html - Веб-интерфейс чата
- chat_history.json - История сообщений
- commands.txt - Очередь команд для Claude
